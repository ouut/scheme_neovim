# VS Code 网页版 Scheme / Strict Paredit 专属极速快捷键手册

> **设计哲学**：
> 1. **彻底废除 Leader 两阶段**：纯单发（One-Shot），按一下立刻生效，绝不搞 Vim 模态！
> 2. **左手大拇指锚定 Alt（Mac: Option / ⌥）**：100% 避开浏览器关闭标签（`Ctrl+W`）、网页后退（`Alt+←`）和 macOS 调度中心（`Ctrl+方向键`）。
> 3. **零浏览器与系统冲突特化**：
>    * **针对 macOS 系统特化**：全套快捷键全面构建在右手 **`H-J-K-L` 四轴八态主键矩阵**，彻底脱离 macOS 全部 5 大系统死键（`E, U, I, N, ~`）！无论使用何种输入法均 100% 免疫死键拦截与字符泄漏！
>    * **针对 Chrome 浏览器内核特化**：将易与浏览器菜单栏和地址栏冲突的键位升级为 **`Alt + X`**（无伤删词）与 **`Alt + \`**（智能排版），彻底杜绝浏览器菜单抢焦！
> 4. **人体工学与空间方位直觉**：
>    * **右手 H-J-K-L 四轴矩阵**：H 轴负责包裹（圆/方）、J 轴负责收缩与切分（Barf/Split）、K 轴负责纵向呼吸（扩选/收缩）、L 轴负责吸入与对调（Slurp/Transpose）。
>    * **W-S 前进与后退**：**`Alt + W`（步进深入 Step Into）** 类似游戏前进冲入深层；**`Alt + S`（步退跳出 Step Out）** 类似后退撤出外层，心智极度清晰。
> 5. **精准领域特化**：绑定统一附加 `editorLangId == 'scheme'` 判定，**在 `.scm` 文件中拥有绝对最高优先级覆盖权**，不干扰其他日常开发。

### ⌨️ 键位分布与人体工学逻辑设计：

1. **最高频核心操作（45%）**：
   * **`Alt + K`（Mac: `⌥ K`，向外扩选）**：右手核心中指/食指下按，连按纵向扩张选中整组括号。
   * **`Alt + Enter` 或 `Ctrl + Enter`（Mac: `⌥ ↵` 或 `⌘ ↵`，发射求值）**：左手拇指锚定 Alt/Ctrl/Cmd，右手一拍回车，立刻送入 Steel REPL 求值。
2. **高频包裹与吞吐（20% ~ 25%）**：
   * **`Alt + H`（Mac: `⌥ H`，圆括号包裹）** 与 **`Alt + Shift + H`（Mac: `⌥ ⇧ H`，方括号包裹）**：Hold/Hug 主键区左侧包裹（彻底脱离 macOS 死键拦截，兼顾 Alt+U/P）。
   * **`Alt + L`（Mac: `⌥ L`，向右吞噬 Slurp）** 与 **`Alt + J`（Mac: `⌥ J`，向左吐出 Barf）**：右手 J（偏左）负责向左吐出收缩，L（偏右）负责向右吸入吞噬，空间左右方位极度自然！
3. **中频结构调整与定点导航（10% ~ 15%）**：
   * **`Alt + Shift + K`（Mac: `⌥ ⇧ K`，向内收缩 Contract）**：方案 A 核心键位，与 `Alt + K` 完美镜像呼应（K 键外扩，加按 Shift 即反向收缩，彻底免疫 macOS 死键，兼容 `Alt+I`）。
   * **`Alt + 1`（Mac: `⌥ 1`，大步后退）** 与 **`Alt + 2`（Mac: `⌥ 2`，大步前进）**：数字键 1 向左后退，2 向右前进。
   * **`Alt + 3`（Mac: `⌥ 3`，选中顶级函数）**：一键直达最外层 `(define ...)`。
   * **`Alt + O`（Mac: `⌥ O`，脱壳解包 Splice）**：Open 打碎外层括号。
4. **低频辅助与微调（2% ~ 5%）**：
   * **`Alt + W`（Mac: `⌥ W`，步进深入 Step Into）** 与 **`Alt + S`（Mac: `⌥ S`，步退跳出 Step Out）**：W 前进深入钻入，S 后退撤出外层。
   * **`Alt + X`（Mac: `⌥ X`，向后整块删除）**：eXterminate/剪切式抹除，100% 避开 Chrome 地址栏抢焦（原 `Alt+D`）。
   * **`Alt + \`（Mac: `⌥ \`，智能格式排版）**：对齐与排版，100% 避开 Chrome 菜单抢焦（原 `Alt+F`）。
   * **`Alt + Shift + L`（Mac: `⌥ ⇧ L`，相邻参数对调 Transpose）**：Leap swap 横向对调。
   * **`Alt + Shift + J`（Mac: `⌥ ⇧ J`，列表切分 Split）**：Joint cut 光标处一分为二（与 J 键同列，零死键）。

## 🎯 17 个快捷键最终映射方案（按使用频率降序）

| 频级 / 占比 | Windows / Linux | macOS (⌥ Option) | 命令动作 | 心智助记符与手指分工逻辑 | 核心功能与效果 |
| --- | --- | --- | --- | --- | --- |
| ⭐⭐⭐⭐⭐<br>(45%) | **`Alt + K`** | **`⌥ + K`** | **向外扩选** (Expand) | 右手主键位纵向扩张 | 自动严丝合缝选中当前 `(...)`，连按扩大一层括号。配合求值极度丝滑！ |
| ⭐⭐⭐⭐⭐<br>(45%) | **`Alt + Enter`<br>或 `Ctrl + Enter`** | **`⌥ + ↵`<br>或 `⌘ + ↵`** | **发射求值** (Eval REPL) | 拇指锚定，右手一拍回车 | 将当前选中的代码立即送入 Steel REPL 运行并吐出结果。 |
| ⭐⭐⭐⭐<br>(25%) | **`Alt + H`** | **`⌥ + H`** | **圆括号包裹** (Wrap Parens) | Hold/Hug 左侧包裹 (零死键) | `cards` $\rightarrow$ `(cards)`，单键把变量变成函数调用。 |
| ⭐⭐⭐⭐<br>(25%) | **`Alt + Shift + H`** | **`⌥ + ⇧ + H`** | **方括号包裹** (Wrap Square) | Hold square 方括号 | `x 10` $\rightarrow$ `[x 10]`，写 `let*` 局部变量和 `cond` 必备。 |
| ⭐⭐⭐⭐<br>(20%) | **`Alt + L`** | **`⌥ + L`** | **向右吞噬** (Slurp) | 右手 L（偏右吸入扩张） | `(a b) c` $\rightarrow$ `(a b c)`，右括号向右跨越一个元素。 |
| ⭐⭐⭐⭐<br>(20%) | **`Alt + J`** | **`⌥ + J`** | **向左吐出** (Barf) | 右手 J（偏左吐出收缩） | `(a b c)` $\rightarrow$ `(a b) c`，右括号向左收缩，踢出末尾项。 |
| ⭐⭐⭐<br>(15%) | **`Alt + Shift + K`** | **`⌥ + ⇧ + K`** | **向内收缩** (Contract) | 右手主键纵向收缩 (与 Alt+K 呼应) | 与 `Alt+K` 呼应，基于历史栈回退，扩选过头随时往回收一级（兼容 `Alt+I`）。 |
| ⭐⭐⭐<br>(10%) | **`Alt + 3`** | **`⌥ + 3`** | **选中顶级函数** (Defun) | 数字区 `3`（定点直达） | 无论光标藏在函数内部多深，一键选中最外层整个 `(define ...)`。 |
| ⭐⭐⭐<br>(10%) | **`Alt + O`** | **`⌥ + O`** | **脱壳解包** (Splice) | Open 剥离外壳 | `(let () (expr))` $\rightarrow$ `(expr)`，打碎外层括号提取内部代码。 |
| ⭐⭐⭐<br>(10%) | **`Alt + 2`** | **`⌥ + 2`** | **大步前进** (Forward) | 数字区 `2`（向右前进） | 光标直接跨过右侧整组完整 S 表达式或参数。 |
| ⭐⭐⭐<br>(10%) | **`Alt + 1`** | **`⌥ + 1`** | **大步后退** (Backward) | 数字区 `1`（向左后退） | 光标直接跨过左侧整组完整 S 表达式或参数。 |
| ⭐⭐<br>(5%) | **`Alt + W`** | **`⌥ + W`** | **步进深入** (Step Into) | W 前进深入钻入 | 光标直接步进跳入当前括号内部最左侧第一个参数前。 |
| ⭐⭐<br>(5%) | **`Alt + S`** | **`⌥ + S`** | **步退跳出** (Step Out) | S 后退撤出外层 | 光标跳回当前外层括号左侧前置位。 |
| ⭐⭐<br>(5%) | **`Alt + X`** | **`⌥ + X`** | **向后整块删除** (Kill Sexp) | eXterminate 删词（免冲突） | 删掉光标右侧的一整组完整子表达式（不破括号，完全避开浏览器抢焦）。 |
| ⭐⭐<br>(5%) | **`Alt + \`** | **`⌥ + \`** | **智能格式排版** (Indent) | 排版与对齐（免冲突） | 一键重新按 Lisp 缩进规范对齐当前 S 表达式代码块（完全避开 Chrome 菜单）。 |
| ⭐<br>(2%) | **`Alt + Shift + L`** | **`⌥ + ⇧ + L`** | **相邻参数对调** (Transpose) | Leap swap 横向对调 | `(equal? a b)` $\rightarrow$ `(equal? b a)`，两项位置瞬间互换。 |
| ⭐<br>(2%) | **`Alt + Shift + J`** | **`⌥ + ⇧ + J`** | **列表切分** (Split) | Joint cut 列表切分 (零冲突) | `(a b \| c d)` $\rightarrow$ `(a b) (c d)`，从光标处把列表切成两半。 |
